Compétences du référentiel

Les six compétences officielles du référentiel BUT Informatique, accompagnées des technologies et des projets qui ont permis de les développer durant ma première année à l'IUT2 Grenoble Alpes.

01 // dev
C1

Réaliser un développement d'application

Développer — c'est-à-dire concevoir, coder, tester et intégrer — une solution informatique pour un client, en respectant ses besoins, en appliquant les principes algorithmiques et en veillant à la qualité du code et de sa documentation.

// Composantes essentielles
  • Développer des applications informatiques simples
  • Partir des exigences et aller jusqu'à une application complète
// Technologies maîtrisées
Java HTML / CSS / JS UML POO Tests
// Projets liés
Bivouacool Chatbot culture générale Site web Hardis
02 // opt
C2

Optimiser des applications informatiques

Proposer des applications informatiques optimisées en fonction de critères spécifiques : temps d'exécution, précision, consommation de ressources… En recensant les algorithmes et les structures de données usuels et en s'appuyant sur des schémas de raisonnement.

// Composantes essentielles
  • Appréhender et construire des algorithmes
  • Sélectionner les algorithmes adéquats pour répondre à un problème donné
// Technologies maîtrisées
Algorithmie Index Dichotomie Structures de données Java
// Projets liés
Chatbot culture générale
03 // sys
C3

Administrer des systèmes informatiques communicants

Installer, configurer, mettre à disposition et maintenir en conditions opérationnelles des infrastructures, des services et des réseaux. Sécuriser le système d'information et optimiser le système informatique d'une organisation.

// Composantes essentielles
  • Installer et configurer un poste de travail
  • Déployer des services dans une architecture réseau
// Technologies maîtrisées
Debian 13 Linux Virtualisation (VM) KDE Plasma Snap / Flatpak Services réseau Git
// Projets liés
Installation poste dev
04 // data
C4

Gérer des données de l'information

Concevoir, gérer, administrer et exploiter les données de l'entreprise et mettre à disposition toutes les informations pour un bon pilotage. En respectant les réglementations sur la protection des données personnelles et en assurant la cohérence et la qualité.

// Composantes essentielles
  • Concevoir et mettre en place une base de données à partir d'un cahier des charges client
  • Optimiser une base de données, interagir avec une application et mettre en œuvre la sécurité
// Technologies maîtrisées
PostgreSQL SQL MCD / MLD Contraintes d'intégrité DBeaver
// Projets liés
BDD Le Tourmentin
05 // mgmt
C5

Conduire un projet

Satisfaire les besoins des utilisateurs au regard de la chaîne de valeur du client, organiser et piloter un projet informatique avec des méthodes classiques ou agiles. En communiquant efficacement avec les différents acteurs du projet.

// Composantes essentielles
  • Identifier les besoins métiers des clients et des utilisateurs
  • Appliquer une démarche de suivi de projet en fonction des besoins
// Technologies maîtrisées
Gestion de projet Recueil de besoins Maquette Documentation Planification
// Projets liés
Site web Hardis Bivouacool
06 // team
C6

Travailler dans une équipe informatique

Acquérir, développer et exploiter les aptitudes nécessaires pour travailler efficacement dans une équipe informatique. En inscrivant sa démarche au sein d'une équipe pluridisciplinaire et en développant une communication efficace et collaborative.

// Composantes essentielles
  • Identifier ses aptitudes pour travailler dans une équipe
  • Situer son rôle et ses missions au sein d'une équipe informatique
// Technologies maîtrisées
Travail en équipe Git / GitHub Communication Répartition des tâches
// Projets liés
Site web Hardis Bivouacool
